# Calculate the following Random Service Costs Calculator Exercise

Welcome, AWS Cloud Practitioners!

In this lesson, you will complete a comprehensive exercise designed to evaluate and compare the costs associated with various AWS services. This practical scenario focuses on cost analysis across different regions and configurations, providing a well-rounded understanding of AWS pricing.

## Exercise Overview

1.  **Amazon S3 Buckets**
    - Configure a basic S3 bucket with one petabyte of data.
    - Create a second S3 bucket in a different region—specifically in Ohio and California—to compare regional pricing differences.

2.  **Kubernetes Clusters on AWS**
    - Set up a Kubernetes cluster on EKS.
    - Configure a similar cluster on ECS.
    - For both EKS and ECS, implement clusters using both the EC2 launch type and Fargate.

    > [!important]
    > **Tip**
    >
    > Ensure that all clusters are set up identically to perform an accurate price comparison between the different configurations.

3.  **AWS Security and Monitoring Services**
    - Set up GuardDuty, AWS Config, and CloudTrail.
    - Evaluate the pricing of these core security and notification services to understand their cost implications.
