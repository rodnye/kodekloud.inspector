# Course Introduction

Welcome to the **Getting Started with HashiCorp Consul** online training course. This hands-on program prepares you for the **HashiCorp Certified Consul Associate** exam and teaches you how to implement Consul for service discovery, configuration, and secure service mesh in modern architectures.

Beyond the [HashiCorp Learn site](https://learn.hashicorp.com/) and official [webinars](https://www.hashicorp.com/webinars), comprehensive Consul training has been scarce. This course fills that gap, combining expert instruction and real-world labs so you can confidently deploy and manage Consul in your environment.

### Lesson Format

Each section follows a consistent structure to reinforce learning:

1.  **Lecture & Slides**  
    Introduce definitions, architecture diagrams, and key concepts.
2.  **Lab Demonstration**  
    Hands-on CLI, UI, and API examples (primarily CLI).
3.  **PDF Resources**  
    Downloadable slides, mind maps, command lists, and lab manuals.
4.  **Quiz**  
    Short assessments to validate your understanding.

![Lesson structure and resources overview](https://kodekloud.com/kk-media/image/upload/v1752877878/notes-assets/images/HashiCorp-Certified-Consul-Associate-Certification-Course-Introduction/course-content-slides-resources-mind-maps.jpg)

You can run demos on your local laptop using the default `.consul` domain or spin up AWS clusters when needed.
