# Section Introduction

In this lesson, we focus on several AWS services that are particularly relevant for the [AWS Certified Developer - Associate](https://learn.kodekloud.com/user/courses/aws-certified-developer-associate) exam. These services are categorized as miscellaneous because they span different functionalities within the AWS ecosystem.

This article explores the following three services:

- AWS AppConfig
- AWS Managed Streaming for Apache Kafka (Amazon MSK)
- AWS Systems Manager
