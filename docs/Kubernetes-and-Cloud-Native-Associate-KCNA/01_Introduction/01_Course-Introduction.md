# Course Introduction

Hello and welcome to the Kubernetes and Cloud Native Associate Certification Prep Course. I’m Mumshad Mannambeth, your instructor for this journey into one of today's fastest-growing and most influential open-source technologies. With 77% of organizations increasing their use of cloud and container technologies, demand for Kubernetes expertise is soaring.

The Linux Foundation offers four certification paths that validate your skills:

- [CKA](https://learn.kodekloud.com/user/courses/cka-certification-course-certified-kubernetes-administrator) – Tailored for administrators.
- [CKAD](https://learn.kodekloud.com/user/courses/ultimate-certified-kubernetes-application-developer-ckad-mock-exam-series) – Designed for application developers.
- [CKS](https://learn.kodekloud.com/user/courses/certified-kubernetes-security-specialist-cks) – Focused on security professionals.
- An entry-level certification that confirms your fundamental understanding of cloud native technologies.

![A person wearing a "KodeKloud" shirt is surrounded by Kubernetes certification badges, including Administrator, Application Developer, Security Specialist, and Cloud Native Associate.](https://kodekloud.com/kk-media/image/upload/v1752880639/notes-assets/images/Kubernetes-and-Cloud-Native-Associate-KCNA-Course-Introduction/frame_40.jpg)

Unlike other Kubernetes certifications that emphasize practical hands-on labs, the KCNA exam utilizes a multiple-choice format. The exam objectives are comprehensive, covering:

- Fundamentals of cloud native computing
- Core Kubernetes concepts and resources
- Scheduling, security, networking, and storage
- Service mesh, observability, and GitOps practices

![A person wearing a "KodeKloud" shirt is speaking, with an illustration of a person at a computer and the text "Multiple Choice Questions" beside them.](https://kodekloud.com/kk-media/image/upload/v1752880640/notes-assets/images/Kubernetes-and-Cloud-Native-Associate-KCNA-Course-Introduction/frame_60.jpg)

> [!important]
> **Note**
>
> Many topics in this course overlap with the objectives of the [CKA](https://learn.kodekloud.com/user/courses/cka-certification-course-certified-kubernetes-administrator) and [CKAD](https://learn.kodekloud.com/user/courses/ultimate-certified-kubernetes-application-developer-ckad-mock-exam-series) exams. If you’re already certified in these areas, you’ll recognize about 70% of the content. However, if you are new to these exams, rest assured—the course starts from the fundamentals.

Each section includes quizzes that help reinforce the concepts, and a comprehensive mock exam at the end ensures you’re fully prepared for the certification exam.

![A person is sitting in a room with a list of cloud computing topics displayed, including Kubernetes and GitOps.](https://kodekloud.com/kk-media/image/upload/v1752880641/notes-assets/images/Kubernetes-and-Cloud-Native-Associate-KCNA-Course-Introduction/frame_70.jpg)

Welcome aboard—I’m excited to guide you through the first section of this article. Let's dive in and start mastering Kubernetes and cloud native technologies!
