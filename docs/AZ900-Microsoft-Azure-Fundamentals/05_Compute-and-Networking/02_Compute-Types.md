# Compute Types

Bella Innovation has successfully organized its Azure environment using management groups and subscriptions. In this lesson, we explore the various compute types available in Azure, guiding you in selecting the best option for migrating your on-premises applications from physical servers to the cloud.

Azure Compute offers flexible, on-demand services by providing essential resources such as CPU, RAM, storage, networking capabilities, and operating systems. The compute spectrum in Azure includes:

- Virtual Machines
- App Services
- Container Instances
- Azure Kubernetes Service (AKS)
- Azure Virtual Desktops
- Function Apps

> [!important]
> **Note**
>
> Each compute option is designed for specific scenarios. By understanding the capabilities and use cases of each service, you can make an informed decision that meets your organization's cloud migration needs.

In the sections that follow, we will examine each of these services in detail. Our goal is to provide you with a clear understanding of their functionalities and when to use them, leading up to a recommendation for the best solution for Bella Innovation.

Let's begin by taking a closer look at Virtual Machines and Virtual Machine Scale Sets.
