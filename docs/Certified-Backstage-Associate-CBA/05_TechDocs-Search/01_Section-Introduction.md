# Section Introduction

## Section Introduction

Backstage offers a unified developer portal with two standout capabilities: a built-in documentation tool and a powerful, platform-wide search. By the end of this lesson, you’ll know how to set up and customize each feature to streamline documentation workflows and make information discovery effortless.

> [!important]
> **Note**
>
> Backstage is an open-source platform designed to centralize your services, documentation, and tooling in one place.
> Visit the [official Backstage site](https://backstage.io/) to learn more.

## Key Features Overview

| Feature                | Purpose                                                     | Benefit                                                         |
| ---------------------- | ----------------------------------------------------------- | --------------------------------------------------------------- |
| Built-in Documentation | Host versioned, Markdown-based docs alongside your code     | Live preview, easy navigation, and automatic sidebar generation |
| Unified Search         | Indexes all portal content—APIs, plugins, and documentation | Fast, contextual search results across teams and services       |

In this lesson, we’ll walk through:

1.  Installing and configuring the Documentation plugin
2.  Structuring your docs for optimal navigation
3.  Enabling and customizing the Search plugin
4.  Fine-tuning search indexing and filters
