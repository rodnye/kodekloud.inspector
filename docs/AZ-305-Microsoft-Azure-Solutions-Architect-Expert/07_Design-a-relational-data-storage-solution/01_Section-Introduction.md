# Section Introduction

In this article, we explore the design of relational data storage solutions with a focus on Microsoft SQL offerings available on Azure. Building on our previous discussion of non-relational data storage—covering unstructured data and NoSQL alternatives—we now shift our attention to the robust world of relational databases.

We will dive into the fundamentals of SQL, examining its key features, availability, and scalability, as well as introducing SQL Edge, a modern solution tailored for edge computing environments.

> [!important]
> **Note**
>
> While there are several relational database systems, including popular options like MySQL and PostgreSQL, this discussion is specific to Microsoft SQL solutions on Azure.
