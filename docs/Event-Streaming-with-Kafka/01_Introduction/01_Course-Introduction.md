# Course Introduction

Welcome to the **Event Streaming with Apache Kafka** course. I’m Raghunandan Sanur, your guide through building real-time data pipelines. Kafka powers over 80% of Fortune 100 systems and processes trillions of messages every day. In this training, you will:

- Master event streaming principles
- Deploy and operate Kafka clusters hands-on
- Analyze how Netflix and LinkedIn scale their infrastructures

By course end, you’ll confidently design and run production-grade Kafka applications.

---

## Course Outline

1.  **Introduction to Event Streaming**  
    What event streaming is, why it matters, and where Kafka fits in modern architectures.
2.  **Building Blocks of Kafka**  
    Explore topics, partitions, brokers, and clusters, and learn how they deliver high throughput and fault tolerance.
3.  **Message Flow in Kafka**  
    Understand how producers publish data, how consumers process it, and how message keys influence partitioning.
4.  **Hands-On Project**  
    Build an end-to-end streaming pipeline—from data ingestion to real-time analytics.
5.  **Exploring Confluent Cloud**  
    Get started with [Confluent Cloud](https://www.confluent.io/confluent-cloud/) and integrate Kafka with major cloud providers.
