# Jenkins Visuals

In today's DevOps landscape, many products are driven primarily by APIs, command-line tools, and programmatic interfaces. However, almost every product also provides a user interface (UI) to interact with its capabilities.

With Jenkins and many other CI/CD platforms, the UI is an essential component. In this article, we will take an in-depth look at the Jenkins UI. You will learn how to navigate through various menu options, trigger builds, manage user accounts, and more. This comprehensive guide is designed to help you efficiently explore and leverage Jenkins for your continuous integration and delivery needs.
