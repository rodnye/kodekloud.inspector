# Hardening Targets

In this article, we explore a comprehensive range of system hardening targets designed to secure modern IT environments. Our discussion focuses on the hardening of essential assets, including mobile devices, workstations, switches, routers, cloud infrastructure, servers, ICS/SCADA systems, embedded systems, RTOS, and IoT devices.

We begin by addressing the primary targets:

- **Mobile Devices & Workstations:** Protecting endpoint devices is crucial as they serve as an entry point for attackers.
- **Network Equipment:** Routers and switches require robust hardening measures to prevent network breaches.
- **Servers:** Ensuring server security is fundamental for maintaining the integrity of applications and data.

![The image lists ten hardening targets, including mobile devices, workstations, switches, routers, cloud infrastructure, servers, ICS/SCADA, embedded systems, RTOS, and IoT devices.](https://kodekloud.com/kk-media/image/upload/v1752872392/notes-assets/images/CompTIA-Security-Certification-Hardening-Targets/hardening-targets-mobile-workstations-routers.jpg)

> [!important]
> **Note**
>
> For a secure infrastructure, it is essential to harden all components—each target plays a significant role in the overall defense strategy.

Beyond these primary targets, the article delves deeper into specialized areas such as SCADA systems, embedded systems, real-time operating systems (RTOS), and IoT devices. These environments often have unique requirements and constraints, making system hardening even more critical.

By understanding the distinct hardening challenges associated with each environment, organizations can implement tailored security measures that improve resilience and reduce vulnerability to cyber threats.

For further insights on system security practices and strategies, consider exploring additional resources on [Security Hardening Best Practices](https://www.cisa.gov/uscert) and [IoT Security Guidelines](https://www.owasp.org/index.php/IoT_Security_Guidance).

Happy securing!
