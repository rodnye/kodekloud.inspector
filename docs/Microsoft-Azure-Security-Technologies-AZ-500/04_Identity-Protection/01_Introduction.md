# Introduction

Welcome back! In this lesson, we are launching a new module titled "Identity Protection." In this module, you will learn how to safeguard the identities of users, groups, and devices within your organization through robust security practices.

Let's take a look at the topics you’ll master in this module:

- An overview of the Azure AD Identity Protection service. Despite its similar name, this standalone service in Azure AD leverages artificial intelligence to conduct comprehensive anomaly checks.
- How to configure risk event detection within Azure AD Identity Protection. We will explore the range of risk events that can be detected and detail the configuration settings required for each.
- Implementing user risk and sign-in risk policies with Azure AD Identity Protection to proactively mitigate potential security threats.
- Setting up Multi-Factor Authentication (MFA) in Azure to bolster security measures and reduce the risk of unauthorized access.
- Applying Azure AD Conditional Access policies to further secure your environment.
- A detailed discussion on access reviews designed to help maintain continuous security compliance.
