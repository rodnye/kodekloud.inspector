# Lens Introduction

Lens is a free, open-source desktop application that provides complete situational awareness for Kubernetes. Whether you are a developer or site reliability engineer (SRE), Lens simplifies cluster management, deployment, monitoring, and troubleshooting in one unified interface.

> [!important]
> **Note**
>
> Lens is compatible with any certified Kubernetes distribution—Minikube, EKS, K3s, K0s—and works seamlessly on-premises or in the cloud.

## Why Lens?

Managing Kubernetes often means switching between multiple tools and command-line interfaces. Even after running various commands, gaining real-time insights into your containerized workloads remains challenging. Lens changes this by consolidating your entire Kubernetes workflow into a single, unified interface—accelerating onboarding, deployment, monitoring, and troubleshooting to boost productivity and reduce time-to-market.

Lens, the Kubernetes IDE, is a one-stop desktop application  
![The image introduces "Lens," a user-friendly desktop application for Kubernetes platforms, highlighting its benefits in improving time to market, productivity, and ROI. It features a screenshot of the application interface and logos of various cloud services like AWS, Azure, and Google Cloud.](https://kodekloud.com/kk-media/image/upload/v1752881174/notes-assets/images/Lens-Kubernetes-IDE-Lens-Introduction/lens-kubernetes-desktop-app-screenshot.jpg)

Developers can push code, deploy, test, and debug directly within Lens.  
![The image illustrates a development workflow using Lens, showing a developer surrounded by various tools and platforms for CI/CD, source code IDEs, and cloud services, with a focus on deployment, observability, testing, and troubleshooting.](https://kodekloud.com/kk-media/image/upload/v1752881175/notes-assets/images/Lens-Kubernetes-IDE-Lens-Introduction/development-workflow-lens-ci-cd.jpg)

For SREs and operators, Lens delivers real-time cluster health, event logs, lifecycle management, and configuration—all in one pane.  
![The image showcases statistics for the world's most popular Kubernetes IDE, highlighting its ranking, GitHub stargazers, user count, and cluster activity.](https://kodekloud.com/kk-media/image/upload/v1752881176/notes-assets/images/Lens-Kubernetes-IDE-Lens-Introduction/kubernetes-ide-statistics-ranking.jpg)

With over 250,000 active users, Lens is the world’s most popular Kubernetes IDE.

Below is a summary of Lens’s core capabilities:

| Feature             | Description                                                                |
| ------------------- | -------------------------------------------------------------------------- |
| Unified Catalog     | Centralized directory for clusters, services, workloads, and tools         |
| Hotbars             | Customizable shortcuts for frequent workflows                              |
| Built-in Prometheus | Pre-integrated monitoring for CPU, memory, network, and filesystem metrics |
| Smart Terminal      | Context-aware terminal across multiple clusters                            |
| Helm Integration    | Browse, search, and install Helm charts without leaving the IDE            |
| Extensions          | Enhance functionality with community and partner plugins                   |
| Spaces              | Securely share cluster access and collaborate in real time                 |

## Unified Catalog

Lens organizes cloud-native resources—clusters, namespaces, workloads, services—into a single searchable catalog. Filter and categorize items to find what you need in seconds.

![The image is a promotional graphic for a cloud-native technology stack, featuring a user interface with a map and a sidebar for organizing clusters and resources. It highlights features like a unified catalog and browsing capabilities.](https://kodekloud.com/kk-media/image/upload/v1752881178/notes-assets/images/Lens-Kubernetes-IDE-Lens-Introduction/cloud-native-technology-stack-ui.jpg)

## Hotbars

Create custom workflows and automation scripts for repetitive tasks. The Hotbars sidebar accelerates common operations, from cluster upgrades to log retrieval.

## Built-in Prometheus

Lens includes Prometheus out of the box. Monitor resource usage—CPU, memory, network, and disk—over any time range, with interactive charts and alerts.

![The image shows a promotional graphic for Lens, a tool that integrates with Prometheus to visualize resource usage metrics like CPU and memory. It features a dashboard with charts and a description of its capabilities.](https://kodekloud.com/kk-media/image/upload/v1752881179/notes-assets/images/Lens-Kubernetes-IDE-Lens-Introduction/lens-prometheus-resource-usage-dashboard.jpg)

## Smart Terminal

Switch contexts seamlessly across clusters without manually updating your kubeconfig. Manage production, staging, and development environments from one terminal window.

## Helm Integration

Search, review, and deploy Helm charts directly within Lens. View chart details, customize values, and install in just a few clicks—no CLI required.

## Extensions

Extend Lens with community and partner plugins. Add vulnerability scanning, resource-relationship visualizations, GitOps workflows, and more.

![The image shows a software interface with a network diagram and code editor, alongside text promoting Lens extensions for cloud-native development.](https://kodekloud.com/kk-media/image/upload/v1752881181/notes-assets/images/Lens-Kubernetes-IDE-Lens-Introduction/network-diagram-code-editor-lens-extensions.jpg)

## Spaces

Lens Spaces is a cloud-based service for secure, collaborative cluster access. Invite team members to view logs, debug services, and review deployments in real time.

![The image is a promotional graphic for Lens, highlighting its "Spaces" feature for sharing Kubernetes clusters and cloud-native resources with a team. It includes a colorful interface showing member roles and a description of the cloud service.](https://kodekloud.com/kk-media/image/upload/v1752881182/notes-assets/images/Lens-Kubernetes-IDE-Lens-Introduction/lens-spaces-kubernetes-promo.jpg)
